# CareerPilot AI — Real-Time AI Interview Preparation Coach

CareerPilot AI is a complete full-stack Generative AI application built to help undergraduate students and entry-level developers prepare for technical interviews. Powered by the official Google GenAI SDK (`@google/genai`), React.js, Node.js/Express, Supabase, Zod, and Tailwind CSS.

---

## 🌟 Features Implemented

1. **Landing Page**: Modern overview highlighting features and quick access to login/register.
2. **Student Authentication**: Supabase Email/Password registration, login, and logout.
3. **Protected Dashboard**: Overview metrics (total sessions, completed sessions, average score, weak topics) and recent history table.
4. **Student Profile Onboarding**: Setup target role, experience level, university, known skills, and weak topics.
5. **Interview Setup**: Configurable target role, interview type (Technical, HR, Mixed), topic, difficulty (Easy, Medium, Hard), and question count (3, 5, 10).
6. **Gemini-Generated Questions**: Questions generated dynamically on backend using `@google/genai` (Gemini 2.5 Flash). Hidden server-side `expected_points` are strictly withheld from frontend until evaluation.
7. **Student Answer Submission & Real-Time Status**: Real-time Supabase status channel updates (`generating_question`, `evaluating_answer`, `generating_feedback`, `saving_result`, `completed`).
8. **AI Answer Evaluation**: Comprehensive scoring (0-10), correct points, missing points, incorrect points, technical feedback, communication feedback, and improved model answer.
9. **Final Interview Report**: Overall score (0-100), performance level, strong/weak areas, technical & communication summaries, revision topics, and next recommended difficulty.
10. **Seven-Day AI Study Plan**: Custom daily learning objectives, learning tasks, and practical exercises generated by Gemini AI.
11. **Supabase Database & RLS**: PostgreSQL tables (`profiles`, `interview_sessions`, `interview_questions`, `interview_answers`, `study_plans`, `progress`) with strict Row Level Security (RLS) policies.
12. **Zod Validation & Repair Retry**: Strict Zod schema validation for all API inputs and Gemini AI responses with 1-step repair retries on model output errors.

## ⚙️ Environment Variables Required

### Client (`client/.env`)
```env
VITE_SUPABASE_URL=https://your-supabase-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
VITE_API_BASE_URL=http://localhost:5000
```

### Backend (`server/.env`)
```env
PORT=5000
SUPABASE_URL=https://your-supabase-id.supabase.co
SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
GEMINI_API_KEY=your-google-gemini-api-key
CLIENT_URL=http://localhost:3000
```

## 🗄️ Database Migration Steps (Supabase)

1. Open your [Supabase Dashboard](https://supabase.com/dashboard) project.
2. Navigate to **SQL Editor**.
3. Copy the contents of [`supabase/migrations/001_initial_schema.sql`](supabase/migrations/001_initial_schema.sql) and execute the SQL query.
4. Verify that the 6 tables (`profiles`, `interview_sessions`, `interview_questions`, `interview_answers`, `study_plans`, `progress`) and RLS policies are created.
5. In **Database -> Realtime**, ensure Realtime is enabled for `interview_sessions`.

---

## 🔑 Gemini API Setup

1. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/).
2. Add `GEMINI_API_KEY=your-key` into `server/.env`.
3. The server uses the official `@google/genai` SDK with `gemini-2.5-flash`.

## 🚀 How to Run Locally

### 1. Install Dependencies
Run from workspace root:
```bash
npm run install:all
```
*(Or install in root, client, and server folders separately with `npm install`)*.

### 2. Configure Environment Files
- Create `client/.env` from `client/.env.example`.
- Create `server/.env` from `server/.env.example`.

### 3. Run Development Server
Run both client (Vite on port 3000) and server (Express on port 5000) concurrently:
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🧪 Testing Steps

Run server unit tests for validation schemas and AI logic:
```bash
cd server
npm test
```

Run TypeScript build check for client and server:
```bash
npm run build
```

## 🌐 Deployment Steps

- **Frontend Deployment (Vercel / Netlify / Render)**:
  - Build command: `npm run build`
  - Output directory: `dist`
  - Set environment variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_API_BASE_URL`).

- **Backend Deployment (Render / Railway / Render)**:
  - Root directory: `server`
  - Build command: `npm run build`
  - Start command: `npm start`
  - Set environment variables (`PORT`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_API_KEY`, `CLIENT_URL`).
